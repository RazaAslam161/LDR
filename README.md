# Miles (LDR App)

A focused web app for couples in long-distance relationships — built around the actual experience of distance.

> Working name: **Miles**
> Tagline: *"Feel close, even from here."*
> Goal: $100/mo recurring revenue within 6 months of launch.

## Documentation

- [Full Roadmap & MVP Spec](./ROADMAP.md)

## Tech Stack

- **Frontend:** Next.js 14 (App Router) + Tailwind CSS
- **Backend:** Supabase (Postgres, Auth, Realtime, Storage)
- **Payments:** Stripe
- **Email:** Resend
- **Hosting:** Vercel
