# Miles — Flutter client

The app itself. Everything about what it does and how it is organized lives in the
[root README](../README.md) and [docs/REFERENCE.md](../docs/REFERENCE.md).

```bash
flutter pub get
flutter test
flutter build apk --release
```

Run `flutter` from this directory — the repo root has no pubspec.yaml. `mobile/.env` is required and
never committed; see `.env.example` for the keys.
