# Miles - vulnerability disclosure
#
# If you have found a security problem in the Miles app, in the backend it
# talks to, or on this site, please tell us. One person builds and runs Miles,
# so replies are human-speed rather than automatic, but every report is read.
#

# is not, the rules for testing, the promise of no legal action for good-faith
# research, and the response times we commit to. Read it before testing.
#

# rather than implied by their absence here.
#
# Expires is a hard date, not a formality: RFC 9116 readers treat this file as
# stale past it. Re-date it, and re-read the policy page, before 18 Aug 2027.
